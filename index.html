about me

Tentang Saya ♡

Fokus saya ada di titik temu antara analisis proses bisnis dan tampilan yang benar-benar bisa dipakai. Saya senang membongkar kebutuhan pengguna lewat wawancara singkat, menerjemahkannya jadi alur fungsional, lalu membangunnya dengan HTML semantik dan styling CSS modern.

Di luar perkuliahan reguler, saya aktif dalam pengembangan sistem informasi berbasis komunitas di kawasan Danau Toba dan mengeksplorasi integrasi komponen UI interaktif multi-perangkat.

Keahlian yang Saya Pakai Sehari-hari

  • HTML5 Semantik
  • Bootstrap 5.3 CDN
  • CSS Grid & Flexbox
  • Aksesibilitas WCAG 2.2
  • Java OOP & Basis Data
  • Git & GitHub Pages

Alur Pengerjaan Proyek Berstandar

  1. Menggali kebutuhan pengguna dan merumuskan spesifikasi masalah nyata.
  2. Menyusun alur informasi, sketsa wireframe, dan arsitektur token warna CSS.
  3. Membangun struktur HTML5 semantik secara terisolasi tanpa styling prematur.
  4. Menerapkan sistem responsif Bootstrap 5 dipadukan dengan Custom CSS Overrides.
  5. Menguji aksesibilitas keyboard, kontras warna, dan responsivitas lintas perangkat.

AndaliTrack — Marketplace B2B Petani Andaliman

Latar Belakang & Solusi

Petani rempah andaliman di Toba sering menghadapi fluktuasi harga pasar yang ekstrem dan rantai tengkulak yang panjang. AndaliTrack memfasilitasi lelang hasil panen langsung ke pelaku industri F&B skala besar.

Fitur Kunci

  • Pencatatan estimasi waktu panen andaliman secara realtime.
  • Sistem penawaran harga transparan langsung dari petani.
  • Desain ramah pembaca layar (WCAG 2.2 Level AA).

Teknologi

HTML5 Semantik CSS Modern Field Research

PartyUp! — Portal Kolaborasi Mahasiswa IT

Latar Belakang & Solusi

Mahasiswa seringkali kesulitan menemukan rekan tim dengan keahlian komplementer (seperti paduan developer dan UI designer) saat mengikuti kompetisi teknologi. PartyUp! menyajikan papan pencarian anggota tim dengan gaya 'adventurer party' ala RPG.

Fitur Kunci

TemanTumbuh — Pemantau Imunisasi & Posyandu

Latar Belakang & Solusi

Buku KIA (Kesehatan Ibu dan Anak) fisik rentan hilang atau rusak, menyebabkan jadwal imunisasi balita terlewat. TemanTumbuh mendigitalkan jadwal vaksinasi dan pencatatan antropometri balita bagi kader posyandu.

Fitur Kunci

  • Kalender pengingat vaksinasi wajib usia 0 - 24 bulan.
  • Visualisasi grafik persentil standar WHO.
  • Desain formulir yang ramah digunakan di smartphone kader.

Teknologi

UI/UX Research Mobile First Aksesibilitas

SIA Del Companion — Dasbor Akademik Mahasiswa

Memberikan antarmuka pendamping yang intuitif dan responsif bagi mahasiswa IT Del dalam mengelola jadwal perkuliahan harian, mengecek riwayat nilai KHS, dan memastikan presensi kuliah di atas ambang batas 80%.
