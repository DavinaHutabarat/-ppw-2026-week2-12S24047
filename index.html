about me

Tentang Saya ♡

Fokus saya ada di titik temu antara analisis proses bisnis dan tampilan yang benar-benar bisa dipakai. Saya senang membongkar kebutuhan pengguna lewat wawancara singkat, menerjemahkannya jadi alur, lalu membangunnya dengan HTML semantik dan CSS modern.

Di luar kuliah, saya aktif di tim lomba teknologi dan mengerjakan proyek yang berakar pada komunitas Batak Toba.

Keahlian yang saya pakai sehari-hari

  • ✧ HTML5 semantik
  • ✧ aksesibilitas WCAG
  • ✧ CSS modern: Flexbox, Grid
  • ✧ Java OOP & Hibernate
  • ✧ Analisis proses bisnis
  • ✧ Git, GitHub & Kolaborasi

Cara saya mengerjakan sebuah proyek

  1. Menggali kebutuhan pengguna dan menuliskannya sebagai daftar masalah nyata.
  2. Menyusun alur informasi dan wireframe kasar sebelum menyentuh kode.
  3. Membangun struktur HTML semantik lebih dulu, tanpa styling sama sekali.
  4. Menambahkan lapisan CSS: tipografi, warna, tata letak, lalu responsivitas.
  5. Menguji dengan keyboard dan layar kecil, baru mempublikasikannya.
