about me

Tentang Saya ♡

Fokus saya ada di titik temu antara analisis proses bisnis dan tampilan yang benar-benar bisa dipakai. Saya senang membongkar kebutuhan pengguna lewat wawancara singkat, menerjemahkannya jadi alur, lalu membangunnya dengan HTML semantik, CSS modern, dan ekosistem Bootstrap 5.

Di luar perkuliahan, saya aktif dalam pengembangan inisiatif teknologi lokal berbasis komunitas dan antusias dalam mengasah keterampilan rekayasa perangkat lunak front-end.

Keahlian yang saya pakai sehari-hari

  • ✧ HTML5 Semantik
  • ✧ Aksesibilitas WCAG 2.2
  • ✧ CSS Grid & Flexbox
  • ✧ Bootstrap 5.3 CDN
  • ✧ Java OOP & Hibernate
  • ✧ Analisis Proses Bisnis
  • ✧ Git, GitHub & Branching

Cara saya mengerjakan sebuah proyek

  1. Menggali kebutuhan pengguna dan menuliskannya sebagai daftar masalah nyata.
  2. Menyusun alur informasi dan wireframe kasar sebelum menyentuh kode.
  3. Membangun struktur HTML semantik lebih dulu, terstandarisasi tanpa styling.
  4. Mengintegrasikan Bootstrap 5 Responsive Grid & Custom CSS Overrides bertema unik.
  5. Menguji kepatuhan aksesibilitas keyboard dan kontras warna sebelum dipublikasikan.

AndaliTrack — Sistem Rantai Pasok Andaliman

Deskripsi Proyek

AndaliTrack adalah platform web B2B yang dirancang khusus untuk memotong rantai perantara dalam distribusi rempah khas Toba, Andaliman. Platform ini memfasilitasi pencatatan panen langsung dari petani hingga masuk ke proses penawaran pembeli skala industri (hotel, restoran, dan produsen bumbu kemasan).

Peran Saya: UI/UX Designer & Front-End Developer
Teknologi: HTML5, CSS3 Grid, Bootstrap 5, Git
